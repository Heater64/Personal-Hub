# Planificación de PersonalHub

Esta carpeta reúne la planificación de **Tamp**, antes PersonalHub. Sirve para organizar las decisiones antes de reconstruir la aplicación y para que cada función tenga un lugar claro.

## Estado de las decisiones

- **Decidido:** confirmado explícitamente por Darwin.
- **Recomendado:** completado con un criterio adecuado para una app privada de dos usuarios; Darwin puede cambiarlo al revisar.
- **Pendiente técnico:** requiere comparar la planificación con el código o validar una migración antes de ejecutarla.

No se deben eliminar datos ni cambiar infraestructura por una decisión solo documental. Al recibir correcciones, actualiza primero los documentos de esta carpeta y luego el código.
